[[win]] By default, MS Windows uses backslashes `\` to separate file path components, but also accepts forward slashes `/` as well.

This is annoying when getting a file path from the command line or from Windows File Exporer, the path is returned with backslashes, but when you try to use the path in a command line or script, you have to replace the backslashes with forward slashes.

Is there a way to make Windows use/report forward slashes in file paths by default?
