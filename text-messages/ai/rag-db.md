[[rag]]

The long term goal is to develop custom AI assistants/chat applications, using multiple cloud based LLM APIs, but custom trained on specialized data sets. There will be two types of data to train on:
- Text Documentation
- Software Source Code - for TypeScript/JavaScript, and Python

The first step is to evaluate approaches and tools.

We want to implement RAG training for out custom data. The LLMs used will be cloud API based, but the RAG database will be on the local development machine. The local RAG database should be free/open source and able to run locally.

First, please evaluate multiple RAG DB options, including `chromadb`, `weaviate`, etc. Discuss in detail the pros/cons of each, and make recommendations.
