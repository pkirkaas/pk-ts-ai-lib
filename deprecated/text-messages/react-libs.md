I am looking for React component libraries and techniques that are compatible with the latest version of React (19-beta). 

{|Resizable Panels|}
One behavior I really want is to have multiple independent components in panels on a web page, that are resizable by the user by dragging the edges of the panels. This is a very common UI pattern for any GUI app. 

There are many NPM React libraries for this. My criteria are:
* The library should be actively maintained and supported.
* It should be compatible with the latest version of React (19-beta).
* It should be easy to use and integrate into a React app.
* It should be well-documented and have a good community.
* It should be easy to nest, with multiple levels of nested vertical and horizontal panels.
 

Please suggest various appropriate libraries and techniques, with pros and cons and examples.
